# Repository Safety Checklist

Before making a repository public, confirm:

- [ ] No passwords
- [ ] No tokens
- [ ] No API keys
- [ ] No private SSH keys
- [ ] No `.env` files
- [ ] No private university files
- [ ] No real personal data
- [ ] No client/company data
- [ ] No weaponized exploit code
- [ ] No unauthorized target information
- [ ] README explains purpose clearly
- [ ] Disclaimer is included
